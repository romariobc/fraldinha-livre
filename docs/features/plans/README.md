# Planos de implementação

Planos descrevem objetivo, escopo, dependências, critérios de aceite e verificações; não exigem modelo específico. A tarefa autorizada e as regras de AGENTS.md prevalecem sobre instruções operacionais antigas dentro de planos.

A pasta ativa contém planos pendentes, parciais ou sem evidência suficiente de conclusão. Presença aqui não significa prioridade ou autorização para executar. O backlog e o estado atual orientam a seleção. Antes de reutilizar um plano antigo, confirme caminhos, contratos e decisões no código atual.
