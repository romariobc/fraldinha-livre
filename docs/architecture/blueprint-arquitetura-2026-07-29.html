Identidade — Firebase Auth

Google + e-mail/senha. Papel (comprador/fornecedor) gravado em users/{uid} no Firestore. O front troca o login por um ID Token; o worker o revalida a cada request — o Firestore não é consultado no caminho quente.

Contrato — packages/contracts

Schemas Zod de Product, Order, Address importados por front e back. Uma mudança de shape quebra o build dos dois lados antes de chegar em produção.

Leilão reverso — gateado

Flag LEILAO_ATIVO=false mantém a UI de mercado visível porém inativa. Vira microserviço à parte na fase 2 (D-014) — não reaproveita este backend diretamente.
